# MD61 — Junny Open Source + Branding + Ownership Strategy

# IMPORTANTE

O projeto Junny será:
# open source

Porém:
# a marca e o ecossistema oficial continuarão pertencendo à Synapto.

---

# Objetivo Estratégico

Permitir:

✅ comunidade  
✅ contributors  
✅ forks  
✅ transparência  
✅ crescimento open source  

SEM perder:

✅ identidade  
✅ branding  
✅ posicionamento  
✅ ecossistema oficial  
✅ governança  

---

## Código

# open source

- MIT

- Junny

- assets oficiais

# propriedade da Synapto

# IMPORTANTE

Forks poderão:
✅ modificar código  
✅ redistribuir código  
✅ criar versões próprias  

Mas NÃO poderão:
❌ usar o nome oficial Junny  
❌ usar branding oficial  
❌ fingir ser distribuição oficial  
❌ utilizar identidade Synapto sem autorização

# Documentation versioning (future)

Today this site documents the **current** `main` branch. When Junny stabilizes with **SemVer** releases, we may:

- Keep **one** English doc set with a version switcher, or  
- Host **v1 / v2** paths for breaking UI or API changes.  

VitePress supports [multi-version setups](https://vitepress.dev/guide/versioning) when the team is ready. No version selector is shown yet to avoid noise during `0.x` development.

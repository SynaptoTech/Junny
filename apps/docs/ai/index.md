# AI features

All AI capabilities are **opt-in**. Nothing is sent to external providers without explicit configuration.

Planned and in-progress items span request generation, response analysis, workflow assistance, and documentation exports. See `/app/ai`, `/app/ai-docs`, and `/app/ai-openapi` for roadmap pages.

## Principles

- Local-first defaults  
- Explicit API keys and providers  
- Clear audit trail of AI-assisted actions

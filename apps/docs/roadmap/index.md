# Roadmap

Junny uses **semantic versioning** (`v0.x.x` today). This page is a **high-level** view, not a committed delivery calendar.

## Shipped (current focus)

- REST, GraphQL, SOAP, WebSocket workspaces  
- Collections, environments, request history  
- OpenAPI import (REST)  
- Local API + SQLite (Prisma)  
- Docker dev environment  
- VitePress documentation (this site)  

## In progress / next

- **Kafka** workspace (see design docs in the monorepo `md/` folder)  
- Deeper **plugin** and extensibility model  
- Tutorials and more **examples** per protocol  
- **i18n** for docs (Portuguese, Spanish) when content stabilizes  

## Not goals (initially)

- Forced cloud or login for basic local use  
- Heavy enterprise-style doc sprawl — keep pages **short and scannable**  

## How to influence direction

- [GitHub Discussions](https://github.com/SynaptoTech/Junny/discussions) for ideas  
- [Issues](https://github.com/SynaptoTech/Junny/issues) for concrete bugs and features  

See [CONTRIBUTING](https://github.com/SynaptoTech/Junny/blob/main/.github/CONTRIBUTING.md) for the contribution flow.

# Enterprise

Junny is **open source and local-first**; enterprise features are an optional layer you grow into.

Topics to be documented here:

- Self-hosted deployment (Docker; Kubernetes-oriented paths later)  
- Organizations, workspaces, and RBAC  
- Secrets vault and audit-oriented workflows  
- Policy and contract governance  

Start with [Getting started](/getting-started/) and track delivery on `/app/enterprise` and `/app/vault`.

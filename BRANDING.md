## Branding guidelines (official assets)

Junny is open source, but the official **Junny branding and assets are owned by Synapto**.

### Official assets

- Name: **Junny**
- Logo / favicon
- Official color palette and visual identity
- Official website and documentation

### Usage rules

- Forks may change the UI and assets freely, but must **remove/replace** the official name/logo/branding if distributing a forked product.
- Do not use Synapto marks or identity in a way that suggests endorsement.
- If you want to reference Junny in documentation/blog posts, use plain text references and avoid using the official logo in a way that implies it is the official project.

### Official links

- Synapto: `https://www.synapto.com.br`
- Website: `https://junny.dev.br`
- GitHub: `https://github.com/SynaptoTech/Junny`

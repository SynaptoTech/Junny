# MD14 — Junny UI/UX Design System

# Objetivo

Este MD define:
- design system oficial
- padrões visuais
- componentes globais
- spacing system
- tipografia
- animações
- guidelines UX
- identidade visual oficial

---

# Objetivo Estratégico

O UI/UX será um dos maiores diferenciais do Junny.

O objetivo NÃO é:
- parecer enterprise antiga
- parecer pesado
- parecer dashboard legado

O objetivo é:
- parecer moderno
- extremamente limpo
- premium
- rápido
- developer-first
